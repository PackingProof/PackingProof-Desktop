# 源码流直存（实验）

这是低配设备的试验性录像模式，默认关闭，只对网络摄像头生效。

## 支持范围

- 源视频编码必须是 H.264 或 H.265/HEVC。
- 开启时仅临时停用摄像头旋转、事件预录缓冲、录像水印和本地音频，不修改这些功能的配置值；关闭源码流直存后恢复生效。
- 摄像头需允许在预览连接之外再建立一路拉流连接。
- 输出为 MKV 容器中的原视频码流，使用 FFmpeg `-c:v copy`，不重新编码。
- 启动等待最多 5 秒，停止收尾最多 8 秒；超时会终止直存进程。

## 行为与限制

- 只保存摄像头原始视频码流，不包含本地麦克风音频、录像水印、缩放或其他画面叠加。
- 直存失败时自动回退到现有帧编码链路。
- 直存进程在录像期间异常退出或文件连续 15 秒没有增长时，当前录像会结束并按失败状态记录，不会继续按成功状态转 MP4。
- 失败录像会从活动录像列表、转换、归档和上传队列中排除，但原始文件保留在磁盘供排查。
- 第二路连接可能顶掉只允许单连接的摄像头主预览；此类摄像头应关闭该模式。
- 人脸识别、面单识别和预览仍使用原有解码帧链路，因此 CPU 和 GPU 不会降为零。

## 验证要求

- 分别使用 H.264、H.265 网络源验证 MKV 能够完整收尾并被 FFmpeg 解码。
- 验证摄像头不支持第二路连接时会自动回退普通录像。
- 验证录像期间断开网络摄像头或终止直存进程时，不会留下“仍在录制”的假状态。
- 验证旋转、预录、水印和本地音频保持原配置时仍可启用直存，相关功能在直存期间被忽略；关闭开关或切换 USB 摄像头后原配置恢复生效。
